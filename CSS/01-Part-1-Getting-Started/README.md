# 🎨 CSS Fundamentals: Universal Styles & Typography

Welcome to Module 1 of my Web Development Journey. This module focuses on setting up structural CSS baselines, typography resets, and consistent cross-browser layout behavior.

---

## 📌 Features & Implementations

* **Universal Reset**: Applied box-sizing standard (`border-box`) alongside reset margins/padding for visual predictability across browsers.
* **Base Typography**: Implemented readable, modern typography cascades with optimal `line-height` and contrast-aware color tokens.
* **Text Formatting**: Structured custom alignment, letter-spacing, and element-specific text decorations.
