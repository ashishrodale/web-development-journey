# 📐 CSS Part 5: CSS Grid Layout

Welcome to **Part 5** of the CSS module! This section covers modern 2D grid layouts, track sizing, alignment, explicit vs. implicit grids, and line-based item placement.

---

## 🎯 Core Concepts Covered

* **Grid Container & Items**: Defining `display: grid` or `display: inline-grid`.
* **Track Sizing**: `grid-template-rows`, `grid-template-columns`, and flexible fractional units (`fr`).
* **Grid Gaps**: Column gap, row gap, and shorthand `gap` properties.
* **Line-Based Placement**: `grid-column-start`, `grid-column-end`, `grid-row-start`, `grid-row-end`, and `span`.
* **Shorthands**: `grid-column` and `grid-row`.
* **Grid Alignment**: `justify-items`, `align-items`, `justify-content`, and `align-content`.
