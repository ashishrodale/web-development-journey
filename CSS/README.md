## 🛠️ Technical Stack & Skills Demonstrated

* **Layout Engines:** Dynamic CSS Flexbox, Scroll-Locked App Layouts (`calc(100vh - 72px)`), Sticky Top Bar (`position: sticky`), Fixed Playback Bar (`position: fixed`)
* **Interactive CSS Tricks:** Pure CSS Heart Wishlist Toggle using `:checked` + Sibling Selectors (`+`), Custom Range Inputs (`::-webkit-slider-thumb` / `::-webkit-slider-runnable-track`)
* **Responsive Architecture:** Media Query Breakpoints (`@media (max-width: 1000px)`), Relative Units (`rem`, `em`, `vh`, `%`), Dynamic Text Truncation (`line-clamp`, `text-overflow: ellipsis`)
* **Design Systems:** Dark Mode Palette (`#000000`, `#121212`, `#181818`), Font Awesome Integration, Google Fonts (`Montserrat`)
* **Code Quality:** Sectioned CSS Architecture, Clean Naming Standards, Non-destructive Custom Scroll Containering
