# 📸 Photography Landing Page with Hamburger Navigation

A sleek, responsive mini-project created using pure HTML5 and CSS3. Features custom UI hover dynamics, interactive navigation highlights, and social media media query scaling.

---

## ✨ Features & Interactive Elements

* **Animated Hamburger Menu:** Expands and scales smoothly upon user interaction.
* **Navigation Overlay:** Dynamic hover states highlighting options (*Gallery, Shortcuts, Exhibition*).
* **Social Link Bar:** Footer social icons (Instagram, Flipkart, YouTube) with scaling hover effects (`transform: scale()`).
* **Background Hero Image:** Clean photography-themed background utilizing full-viewport styling (`100vh`).

---

| Technology | CSS / HTML Concepts Applied |

| **HTML5** | Semantic structure, navigation lists, link elements |
| **CSS3 Layouts** | Flexbox positioning, `position: fixed` / `absolute` overlay |
