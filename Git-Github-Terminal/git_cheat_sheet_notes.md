# Git & GitHub Workflow Notes

## Local Repository Operations
1. `git init` - Initializes Git in current directory.
2. `git status` - Shows untracked and modified files.
3. `git add .` - Stages all local changes.
4. `git commit -m "feat: update documentation"` - Commits changes with message.

## Branching & Merging
1. `git branch` - View existing branches.
2. `git checkout -b feature-branch` - Create and switch to new branch.
3. `git merge feature-branch` - Merge feature branch into active branch.

## Remote Synchronization
1. `git remote add origin <URL>` - Link local repo to remote GitHub URL.
2. `git push -u origin main` - Push commits to GitHub.
3. `git pull origin main` - Download remote updates to local environment.
