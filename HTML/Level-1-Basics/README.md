# 📌 HTML Level 1: Basics & Fundamentals

This directory covers the basic building blocks of HTML, including document structure, text formatting, hyperlinks, images, and lists.

## 🧠 Topics Covered
* **Boilerplate Structure**: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
* **Headings & Paragraphs**: `<h1>` to `<h6>`, `<p>`
* **Links & Media**: `<a>` (anchor), `<img>` (image) with `src` and `alt` attributes
* **Lists**: Unordered (`<ul>`), Ordered (`<ol>`), and List Items (`<li>`)
* **Key Notes**: HTML comments (``), case-insensitivity rules.
