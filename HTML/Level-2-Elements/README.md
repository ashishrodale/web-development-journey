# 📌 HTML Level 2: Block vs Inline, Semantic Tags & Entities

This directory covers structural elements, layout containers, semantic markup, formatting tags, and HTML entities.

## 🧠 Topics Covered
* **Block vs Inline Elements**: Difference in layout behavior (`div` vs `span`)
* **Formatting Tags**: `<hr>`, `<sup>`, `<sub>`
* **Semantic Tags**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
* **HTML Entities**: Special symbols like `&nbsp;`, `&lt;`, `&gt;`, `&amp;`
* **Emmet Shortcuts**: Speeding up development with shorthand syntax
