# 🟨 JS Part 1: JavaScript Basics & Fundamentals

This directory contains introductory exercises covering core JavaScript syntax, data types, console logging, variable scoping, string practices, and basic arithmetic/assignment operations.

---

## 📑 Syllabus & Topics Summary

| Topic | Description | Status |
| :--- | :--- | :---: |
| **Console Output** | `console.log()` usage and Chrome DevTools console testing | ✅ |
| **Data Types** | Primitive types: `Number`, `String`, `Boolean`, `Undefined`, `Null` | ✅ |
| **Variables** | Memory allocation using `var`, `let`, and `const` | ✅ |
| **Operations** | Arithmetic (`+`, `-`, `*`, `/`, `%`, `**`) & Assignment (`+=`, `-=`) | ✅ |
| **Unary Operators** | Increment (`++`) and Decrement (`--`) syntax | ✅ |
| **Strings & Indices** | String indexing, `.length` property, and character access | ✅ |
| **Template Literals** | Backtick syntax (`${var}`) for dynamic string formatting | ✅ |

---

## 📁 Source Files
* 📄 [`index.html`](./index.html) - Entry HTML file linking external JavaScript code.
* 📜 [`app.js`](./app.js) - Script file executing exercises for all Part 1 topics.
