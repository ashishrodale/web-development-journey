# JavaScript Part 12: Async/Await & Working with APIs

> Comprehensive documentation and hands-on code covering Asynchronous JavaScript, Async/Await syntax, Error Handling with `try...catch`, JSON processing, HTTP protocols, Request Parameters, Headers, and the modern `fetch` API.

---

## 📌 Core Topics Covered

* **Async & Await:** Writing cleaner asynchronous code using `async` functions and the `await` keyword.
* **Rejection & Error Handling:** Gracefully catching errors using `try...catch` blocks within asynchronous functions.
* **APIs & JSON:** Understanding Application Programming Interfaces, HTTP Verbs (GET, POST, etc.), HTTP Status Codes, and JSON parsing (`JSON.parse()`, `JSON.stringify()`).
* **AJAX & Web Requests:** Asynchronous JavaScript and XML concepts, API testing tools, adding parameters to URLs, and configuring HTTP Headers.
* **Fetch API:** Consuming external web APIs using `fetch()` with `async/await`.
