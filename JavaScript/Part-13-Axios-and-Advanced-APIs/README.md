# JavaScript Part 13: Axios & Advanced API Operations

> A production-ready repository documenting hands-on implementations of HTTP client libraries (Axios), dynamic media API consumption, custom HTTP header configuration, URL query string parameter construction, and project API integration workflows.

---

## 📌 Core Topics Covered

* **Axios HTTP Client:** Making asynchronous GET/POST requests using Axios for cleaner syntax and automatic JSON transformations.
* **DogPictures API Integration:** Dynamically fetching and rendering image endpoints from third-party APIs onto the DOM.
* **HTTP Headers with API Requests:** Passing custom and authorization headers (`User-Agent`, `Accept`, `Authorization`) in Axios request configurations.
* **Query String Activity:** Building search utilities and dynamic endpoints using URL query string parameters (`?key=value`).
* **Curated Free APIs:** Utilizing popular, open-access public APIs for frontend project development.

## 💻 How to Run & Test

1. Include the Axios CDN (`<script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>`) in your HTML head or scripts section.
2. Launch `index.html` or `assignments/assignment_runner.html` using **VS Code Live Server** or directly in your web browser.
3. Open Developer Tools (**F12** $\rightarrow$ **Console** & **Network** tabs) to inspect network calls, query params, request headers, and returned payloads.
