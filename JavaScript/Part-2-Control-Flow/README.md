# ⚡ JavaScript Part 2: Control Flow, Logic & Operators

Welcome to Module 2 of the JavaScript series! This module covers decision-making statements, conditional evaluations, logical operations, interactive dialogs, and fundamental string checks.

---

## 📌 Topics Covered

* **Conditional Statements**: `if`, `else if`, `else`, and Nested `if` statements.
* **Switch Statements**: Multi-way branching using `switch`, `case`, `break`, and `default`.
* **Logical Operators**: AND (`&&`), OR (`||`), and NOT (`!`).
* **Truthy & Falsy Values**: Evaluation of falsey types (`0`, `""`, `null`, `undefined`, `NaN`, `false`).
* **Interactive Dialogs**: `alert()`, `prompt()`, and `console.warn()` / `console.error()`.
* **String Analysis**: Properties like `.length` and character indexing `.charAt()`.
