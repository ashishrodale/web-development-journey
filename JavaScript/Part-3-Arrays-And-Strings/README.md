# JavaScript Part 3 — Core Fundamentals & Methods Showcase

This repository module demonstrates core JavaScript concepts, focusing on **String Manipulation**, **Array Data Structures**, and **Array Methods**. It contains live diagnostic code alongside 6 completed assignment logic scripts structured in a clean, production-ready architecture.

---

## 📌 Module Overview & Core Concepts

| Topic / Category | Concept Learned | Primary JavaScript Methods / Syntax |
| :--- | :--- | :--- |
| **String Manipulation** | In-place operations & Immutability | `.trim()`, `.toUpperCase()`, `.toLowerCase()` |
| **String Searching & Extraction** | Substring identification & slicing | `.indexOf()`, `.slice()`, `.replace()`, `.repeat()` |
| **Method Chaining** | Sequential execution on data | `str.trim().toUpperCase().slice()` |
| **Array Core Operations** | Mutability & Stack/Queue patterns | `.push()`, `.pop()`, `.shift()`, `.unshift()` |
| **Array Searching & Manipulation** | Element checking & slicing/splicing | `.indexOf()`, `.includes()`, `.slice()`, `.splice()` |
| **Array Reordering & References** | Array operations & references | `.concat()`, `.reverse()`, `.sort()`, `const` arrays |
| **Multidimensional Data** | Nested structures & indexing | Matrix access via `grid[row][col]` |
