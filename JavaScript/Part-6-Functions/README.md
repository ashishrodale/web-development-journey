# JavaScript Part 6: Functions & Execution Scope

> Comprehensive documentation, exercises, and assignment implementations covering JavaScript functions, arguments, parameters, return values, array processing, string manipulation, and random number utilities.

---

## 📌 Core Concepts Covered

* **Function Basics & Syntax:** Function declarations, parameters, arguments, and function invocations.
* **Return Statements & Scope:** Returning values from functions, execution context, and local scope.
* **Control Flow in Functions:** Incorporating loops and condition checks inside functions for table generators and sequence sums.
* **Array & String Processing:** Filtering elements, extracting unique characters, string concatenation, and array searches.
* **Math Utility Functions:** Building random number generators and dice-rolling algorithms using `Math.random()` and `Math.floor()`.
