# JavaScript Part 9: DOM (Document Object Model) Manipulation

> Comprehensive documentation and hands-on exercises covering DOM Selection, Manipulation, Attributes, Dynamic Element Creation, classList Methods, and Navigation.

---

## 📌 Core Topics Covered

* **DOM Selection:** `getElementById`, `getElementsByClassName`, `getElementsByTagName`, `querySelector`, and `querySelectorAll`.
* **Content Manipulation:** Updating inner text using `innerText`, `textContent`, and `innerHTML`.
* **Attribute Control:** Reading and modifying element attributes via `getAttribute()` and `setAttribute()`.
* **Style & Class Control:** Inline styling via `.style` and dynamic class toggling with `.classList` (`add`, `remove`, `toggle`, `contains`).
* **DOM Navigation & Element Lifecycle:** Traversing nodes (`parentElement`, `children`), creating elements (`createElement`), and appending/removing them (`append`, `appendChild`, `remove`, `removeChild`).
